## 리포트 v6.10 변경점 (2026-11-18) · MDD 점검·세션 상세·시간별 개선 제안
- MDD: 누적 곡선 계산은 맞았습니다(1,146핸드 기준 −101.9만, 파이썬 재계산과 일치). 고점·저점 세션과 현재 낙폭을 같이 보여줍니다.
- 세션 시작 시각: 첫 핸드 저장 시각(UTC)이 아니라 세션 ID의 실제 시작 시각을 한국 시간(KST)으로 표시하고 종료 시각을 덧붙입니다. 세션 정렬도 시작 시각 기준입니다.
- 세션 상세: 세션 목록에서 세션을 누르면 핸드별 표(시각·포지션·패·보드·내 라인·결과·손익·누적·정본 점검)가 열리고, 핸드를 누르면 스트리트별 전체 액션과 내 결정 점검, 쇼다운 공개 패가 나옵니다. 핸드 상세는 최근 500핸드만 보관됩니다.
- 현장 관찰 vs 트레이너: 세션·기록 탭에서 현장에서 본 플랍 인원·림프·프리플랍 레이즈·3벳/캡·캡 주도 인물을 기록하고 트레이너 최근 핸드의 같은 수치와 비교합니다(2026-11-18 회장님 관찰: 플랍 4~5명, 림프·레이즈 많음, 캡은 평균이며 특정 인물이 자주).
- 상대별 핸드 리뷰: 세션·기록 탭에서 성향별·이름별(이름+성향 조합)로 본 핸드·참여율·레이즈·참여 팟·내 손익/팟·내 교정을 보고, 행을 누르면 그 상대가 참여한 핸드와 스트리트별 진행을 봅니다.
- 개선 제안 카드: VPIP 하락 경고를 없애고 '정본 참여 이행'(정본이 참여인 핸드에서 실제 참여)·'정본 밖 참여' 지표로 교체했습니다. VPIP·PFR은 정본의 결과라 목표가 아닙니다.
- 누적 시간별 개선 제안: 세션 경과 구간(0~1h, 1~2h, 2~3h, 3h+)별 BB/100(±오차)·VPIP·PFR·판단 시간·정본 오답률과 시작 시간대·세션 길이별 표, 자동 제안.

## v6.9.7 변경점 (2026-11-18) · 핸드리뷰에서 채점 보류 결정에도 모델 권장 표시
- 문제: 정본이 없는 결정(전체의 약 80%)은 모델이 EV·혼합·승률을 이미 계산해 두고도 핸드리뷰 권장 칸에 "상황 재계산"만 떴다.
- 수정: 채점은 그대로 제외하되 권장 칸에 모델 답을 보여 준다. 우선순위는 솔버 혼합 → 행동별 EV 비교 → 모델 판단(rec) → 규칙 후보 → 프리플랍 매트릭스·림프 팟 모델 → 승률 vs 필요 승률. EV가 근소하면 "체크 ≈ 벳 비슷"처럼 함께 보여 주고 선택이 그중 하나면 "모델과 같음"으로 본다. 필요 승률 15% 이하인데 폴드로 나오면 콜로 보정한다.
- '왜?'에는 내 핸드 등급·드로우, 추정 승률 vs 필요 승률(팟 배당), 행동별 EV 금액, 보드 위험을 풀어서 적는다. '다음엔'도 모델과 내 선택이 같은지·다른지에 맞춰 달라진다.
- 확인: 2026-11-17 기록의 채점 보류 815건 모두 권장이 나온다. 내 선택과 일치율은 프리플랍 78%, 플랍 75%, 턴 69%, 리버 61%.

  - 등급5는 현장 루즈 플레이어가 실제로 림프하는 그럴싸한 패: 모든 Ax, 수딧 K·Q, 높은 오프 브로드웨이, 수딧 갭퍼, 오프 커넥터. 정크(72o·K3o 등)는 루즈 스타일도 1~6%만 친다.
  - 스스로 림프한 사람은 레이즈가 와도 대부분 따라오고, 10만은 이미 2명 이상 들어간 팟이면 한 등급 더 넓게 따라온다.
  - 실력이 낮을수록 경계 패에서 한 등급씩 흔들린다.
- **측정(히어로 전부 폴드, 10만 52핸드):** 플랍 진입 평균 4.1명, 레이즈 뒤 따라오는 인원 3.4명, 레이즈 직면 폴드율 36%, 정크 진입 0건. 30만은 레귤러 비중 때문에 플랍 3.1명·폴드율 약 60~70%로 더 단단하다. 수치는 잠정이며 현장 관찰로 조정한다.
- 강원랜드 프로필이 아닌 Normal·Soft·Reg Heavy는 기존 로직 그대로다.

- **구성**: `sync.js`(신규) + Google Apps Script 웹앱(`Poker OS Trainer Sync`) + Google Drive JSON 2개.
  `index.html`·`report.html`이 `<head>`에서 `sync.js`를 함께 불러옵니다. `sync.js`의 `CFG.endpoint`를 비우면 예전처럼 이 브라우저에만 저장됩니다.
- **동기화 대상**: 최근 핸드(`poker_os_history_v5_lzw1`, LZW 그대로), 손익 원장(`poker_os_pl_ledger_v1`, 최대 30,000행), 진행 세션(`..._active_session_v30`), 약점(`poker_os_leaks_v1`), 솔버 학습(`poker_os_solver_learning_v2`), 단골 관찰(`poker_os_regular_memory_v1`), 훈련 프로필(`..._training_profile_v30`), 바이인(`poker_os_hero_buyin_v1`), 팟가드(`poker_os_potguard_v1`), 실전 기록(`poker_os_real_sessions_v1`), 리포트 설정(`poker_os_report_prefs_v1`), 현장 관찰(`poker_os_field_obs_v1`).
- **전체 아카이브**: IndexedDB `poker_os_archive_v1`(500핸드 초과분)는 자동 경로에서 제외하고, 동기화 패널의 “전체 아카이브 백업/복원”으로 200핸드씩 주고받습니다(콜드 Drive 파일 `poker_os_trainer_archive.json`, 최대 4,000핸드).
- **병합 규칙(기록 보존)**: 핸드는 앱 가져오기와 같은 키(`savedAt|handNo|position|hole`), 원장은(`t|sid|pl|hn`)로 합집합. 학습/설정은 카운터 최대값(`deepMax`), 세션은 `savedAt` 최신 우선이며 **진행 중인 로컬 세션은 절대 덮지 않습니다**. 서버도 저장 전에 같은 합집합 병합을 하고, 설정 키는 `t`(ms)가 더 새로운 쪽만 받습니다.
- **자동화**: 기록 변경 시 2초 디바운스 푸시, 90초 폴링(탭이 보일 때만), 탭 복귀·온라인 복구·페이지 종료 시 1회. 상단에 `☁️ 동기화됨 / 동기화 중… / 오프라인` 배지, 누르면 수동 `[지금 동기화] [클라우드 불러오기] [클라우드 저장] [전체 아카이브 백업/복원] [JSON 백업]` 패널.
