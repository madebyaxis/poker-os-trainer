## v5.8 변경점 (2026-11-16) · 속도 개선 · 방화범 비공개 · 방화범도 사연 있게
- **속도:** 히어로가 액션할 때마다 모델 에퀴티(몬테카를로)를 동기 계산해 리버에서 150~600ms 멈췄다. 히어로 차례가 오면 미리 계산해 두고(같은 공개 상태 캐시), 범위 샘플링의 카드 키 생성을 1회로 줄였다. 측정: 리버 히어로 액션 150~600ms → 약 4ms. 핸드 종료 때 500핸드 기록을 여러 번 압축 해제·압축하던 것을 메모리 캐시 + 0.7초 뒤 1회 저장으로 바꿨다(페이지를 떠날 때 즉시 저장). AI 액션 간격 260→170ms, 히어로 폴드 후 70ms.
- **방화범 비공개:** 좌석의 방화범 표시와 현장 바의 방화범 이름을 없앴다. 누가 공격적인지는 액션과 쇼다운으로 직접 읽는다. 공격 테이블 프로필을 고르면 바에 "직접 읽으라"는 안내만 뜬다.
- **방화범도 사연 있게:** 프리플랍 정크(등급6) 진입을 없애고 등급5는 뒷자리 위주. 포스트플랍 공격은 페어·드로우·오버카드 2장·주도권·겁주는 카드가 있을 때만. 아무것도 없으면 체크·폴드한다. 측정(공격 테이블 44핸드): 턴·리버 에어 먼저 벳 0%, 턴·리버 에어로 벳 맞으면 폴드 100%.

## v5.6 변경점 (2026-11-16) · 사연 있는 포스트플랍 + 30만 현장 테이블
- **포스트플랍(강원랜드 프로필):** 패 등급(strong/good/marginal/weak/air) + 실제 드로우 아웃츠(거셧 4·양차 8·플러시 9·콤보 15) + 가격 + 이번 스트리트 레이즈 여부로 결정한다(`kangwonPostflop`).
  - 약한 패(바텀 페어·보드만·A하이)는 턴·리버에서 거의 따라오지 않는다. 레이즈가 나온 스트리트에서는 약한 패가 콜하지 않는다.
  - 블러프는 사연이 있을 때만: 주도권 c-bet(헤즈업·3way), 겁주는 카드가 떨어진 헤즈업 턴 배럴, 모두 체크한 헤즈업 막자리 스틸, 헤즈업 리버 소량. 4명 이상 멀티웨이 순수 블러프는 거의 없다.
  - 측정(30만 54핸드): 플랍 먼저 액션 시 에어 벳 1%, 턴·리버 에어 벳 0%, 리버 에어·약한 패 벳 직면 폴드 100%, 턴 약한 패 직면 폴드 100%.
- **30만 테이블:** 필드를 레귤러 2~4명 + 루즈 패시브·콜링스테이션 다수 + 매니악 소수로 바꾸고, 단골에 '캡 아저씨'(엄태호) 1명을 둔다. 레귤러도 앞자리는 림프가 많고, 림프한 사람은 레이즈에 거의 콜하며, 캡은 캡 아저씨 외에는 드물다(QQ+/AK도 절반은 콜).
  - 측정(30만 54핸드): 플랍 진입 3.8명(이전 3.1), 핸드당 림프 2.3명, 레이즈 뒤 따라오는 인원 2.6명(이전 1.2), 3벳·캡 나온 핸드 1.9%.

## v5.5 변경점 (2026-11-16) · 강원랜드 현장형 프리플랍 범위
- **문제:** AI가 K3o·72o·T2o·93o 같은 패로 들어오는 반면, 레이즈가 나오면 현장보다 쉽게 폴드했다(측정: 10만 플랍 진입 약 3명, 레이즈 뒤 따라오는 인원 약 1.9명).
- **해결:** 강원랜드 프로필(10만·30만 현장)에서는 시작 패를 5개 등급 + 정크로 나누고, 스타일별로 "먼저 들어가는 최대 등급 / 먼저 레이즈 / 레이즈에 새로 콜 / 이미 림프한 뒤 레이즈에 콜 / 리레이즈" 기준으로 프리플랍을 결정한다(`KANGWON_PF_STYLE`).
  - 등급5는 현장 루즈 플레이어가 실제로 림프하는 그럴싸한 패: 모든 Ax, 수딧 K·Q, 높은 오프 브로드웨이, 수딧 갭퍼, 오프 커넥터. 정크(72o·K3o 등)는 루즈 스타일도 1~6%만 친다.
  - 스스로 림프한 사람은 레이즈가 와도 대부분 따라오고, 10만은 이미 2명 이상 들어간 팟이면 한 등급 더 넓게 따라온다.
  - 실력이 낮을수록 경계 패에서 한 등급씩 흔들린다.
- **측정(히어로 전부 폴드, 10만 52핸드):** 플랍 진입 평균 4.1명, 레이즈 뒤 따라오는 인원 3.4명, 레이즈 직면 폴드율 36%, 정크 진입 0건. 30만은 레귤러 비중 때문에 플랍 3.1명·폴드율 약 60~70%로 더 단단하다. 수치는 잠정이며 현장 관찰로 조정한다.
- 강원랜드 프로필이 아닌 Normal·Soft·Reg Heavy는 기존 로직 그대로다.

## v5.3 변경점 (2026-11-15) · 강원랜드 현장형

- **현장 시계 바:** 핸드 수 ÷ 30핸드/h로 현장 환산 시간, 세션 손익(원·BB), 시간당, 레이크, 콤프(10만 2천/h, 30만 3천/h), 스톱 라인을 테이블 위에 표시한다. 10만은 Founder 확정선(−20만 종료, +25만 검토, +30만 종료, 10시간). 30만은 10만 기준을 BB로 환산한 참고선이다. 선을 넘으면 로그와 힌트로 알린다(훈련은 계속 가능).

- **손익 원장:** 핸드별 요약을 `poker_os_pl_ledger_v1`에 따로 쌓아 500핸드 보관 제한과 무관하게 누적 리포트를 만든다. 첫 실행 때 기존 기록에서 채운다.
